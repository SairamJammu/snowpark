# SnowPark

SnowPark uses GIS to compare winter terrain and sunlight across Kent State surface parking areas. The current pilot ranks 74 candidate surfaces using modeled winter radiation, terrain shade, and aspect.

- [Pilot methods, data sources, and run instructions](docs/terrain_pilot.md)
- [Pilot results](outputs/tables/terrain_pilot.csv)
- [White Hall boundary review](docs/parking_boundary_review.txt)

The index describes relative terrain exposure. Field observations are needed to validate snow persistence. ArcGIS Pro projects, geodatabases, and elevation rasters are stored locally.

Parking geometry: © OpenStreetMap contributors (ODbL). Elevation: USGS 3DEP.
